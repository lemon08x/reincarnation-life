# 单局成长玩法重构方案

日期：2026-09-08。状态：玩法设计提案，尚未实现。已根据“人生轨迹具有随机性，童年不能决定最终职业”的要求修订。当前运行规则仍见 [Game_Design.md](../Game_Design.md)。

## 1. 核心约束

**人生去向不预定，经历积累要有用。**

开局不选定终身职业，不承诺“成为某人”的固定主线，也不在童年选择后锁定结局。出生、环境、时代变化、遇到的人和可获得的机会共同影响人生；玩家在这些条件下回应、准备、争取或放弃。

成长必须让玩家越来越有办法，但不能让人生自动沿一条职业阶梯上升。角色可能转行、迁居、暂时失业、失去一次机会，也可能发展出意料之外的生活。已学会的本领、形成的处事方法和真实关系应当在合理的新处境中继续产生作用。

核心循环：

**遇见随机但有来由的处境 → 选择回应或主动准备 → 留下经历并获得积累 → 积累改变后续方法与机会 → 抓住机会或转向 → 看见积累的回报。**

上一版的“小城木匠”固定主线撤销。木作只作为一种可能接触的经历和阶段生活，不再是整局预定身份。

## 2. 哪些随机，哪些由玩家影响

| 层面 | 系统提供什么 | 玩家影响什么 |
| --- | --- | --- |
| 出身与早年 | 家庭条件、生活环境、初始接触的人与事 | 如何回应，优先投入哪种积累 |
| 人生机会 | 根据年龄、地点、关系、能力和环境生成可遇见的机会 | 接受、拒绝、准备、主动争取或选择替代办法 |
| 环境变化 | 搬迁、行业变化、他人的决定、偶发困难与好运 | 用已有积累应对，保住什么，是否转向 |
| 成长 | 事件声明的可靠成长收益与真实来源 | 通过行动决定学会什么、建立什么关系、付出什么资源 |
| 身份与成果 | 满足条件后出现的阶段机会 | 是否投入并完成实际行动，形成什么生活 |

随机不直接把角色从学徒改写成商人，也不随机宣布已经积累的技能失效。环境可以让原来的路受阻；新的身份要由事件、实际行动和结果建立。

玩家可以表达阶段愿望，如“这几年想多挣钱”“想学门本领”“想离家看看”。愿望用于提供相关准备行动和适度影响机会权重，不保证指定工作一定出现，也不构成长期任务失败条件。

## 3. 成长沉淀在哪里

成长分为可迁移的能力、具体本领和处境资产。前两者回答“我会做什么”，后者回答“我现在有什么条件”。

### 3.1 可迁移的能力

首个原型可用三类作为内容组织和行动门槛，数值先采用短刻度，平衡后再确定范围：

| 能力 | 实际含义 | 可发挥作用的不同场合 |
| --- | --- | --- |
| 动手 | 观察结构、使用工具、处理实物问题 | 修理、维护运输工具、改造住处 |
| 沟通 | 说明情况、协商安排、理解他人诉求 | 家庭分工、委托报价、合作纠纷 |
| 筹划 | 安排步骤、核算资源、协调顺序 | 订单交付、行程安排、小店经营 |

它们不是三条职业路线。一个人可以多项积累，同一能力可以在不同生活中使用。每次增长必须对应实际行动，不把任何遭遇都转换成相同经验。

### 3.2 具体本领与处事专长

具体本领来自真实实践，例如“修补木器”“记账”“带新人”。本领比通用能力更有针对性，带来专属选项或更好的结果。

两次回望各形成一个处事专长，例如“先检查再动手”“先把约定说清”。回望的选择来自已发生的证据，不能凭空授予从未接触的职业技能。首版每局最多两个专长。

本领和专长不会因为换职业自动消失，但只在适用场景生效。会修木器可以帮助维修木箱、照顾自己的住处，不能直接等同于精通所有机械或医学。

### 3.3 处境资产

- 家底：可以花费的资源，用于材料、搬迁、尝试和生活安排。
- 关系与信誉：保存在具体人物、群体和承诺上，通过真实推荐或交往发挥作用。
- 身份与场所：当前工作、经营的店、拥有的工具或工作空间，开放当下可执行的行动。

一个地方的信誉不会自动变成所有陌生人的信任；如要跨地方产生作用，需要真实的推荐、作品或介绍。失去职位会影响收入和身份行动，但不会同时清空所有能力、关系与过去成果。

不再增加通用人生点。行动费用使用真实资源；机会成本写成需要放弃或延后的具体事情。

## 4. 同样的早年经历，可以通向不同的人生

共同起点：少年时帮周师傅修好一个木箱，获得初步动手能力，记下一段合作经历。

| 随后遇到的情况 | 玩家可能的选择 | 逐渐形成的生活 | 早期成长怎样兑现 |
| --- | --- | --- | --- |
| 周师傅有意收徒，家里暂时能支持 | 留下来继续练习 | 修理、制作、独立接单 | 基础方法帮助完成复杂修复 |
| 家里搬到码头附近，货栈缺人 | 去货栈工作，也继续学安排货物 | 运输、调度、带人 | 修箱和判断损坏减少货损；新经历再发展筹划 |
| 亲属的小店需要照看 | 留店帮忙，逐渐接手事务 | 店铺经营、邻里生活 | 维修货架省下成本；沟通与记账逐渐成为主要本领 |

三条路线都不是在木箱事件时确定的。后续还可以交叉：货栈关闭后去经营小店，做木作的人也可能因为伙伴邀请转向教学或经营。

这些是事件组织示例，不要求每局抽中所有分支，更不要求把人物随机改名后走同一套职业剧情。

## 5. 机会生成与人生连续性

### 5.1 先检查合理性，再随机

每次推进先根据当前年龄、地点、关系、身份、已完成事件和环境筛选合理内容，再在候选内容中抽样。能力和关系改变机会权重、可选方法及结果，不提前选定终身路线。

候选内容包含：

1. 当前生活的延续：正在做的事、真实承诺和后续结果。
2. 相邻机会：已有能力可以帮助争取，但还需要新的投入。
3. 外部变化：带来转向的环境变化或新相遇，需要符合当前处境。

当前事务优先保持连贯，不能为了随机性每次都换一套无关人物。一次学习、工作或合作可以形成连续的两三场事件，再自然结束、延续或转向。

### 5.2 开放机会不等于保证成功

角色有木作经验，可以更容易得到修理活，也可以通过检查货箱争取货栈的工作。角色没有实际学习经营，就不能因为动手能力高直接接管大商行。

稀缺的身份与重大机会允许错过；普通成长途径必须持续存在。错过正式学徒机会后，仍可以通过自家修理、短工或普通委托保持能力有用，但这些途径不保证拿到同样的职位、收入和名望。

### 5.3 玩家可以争取

在合适的节点，提供拜访旧识、练习本领、打听工作、留出搬迁费用等行动。这些行动消耗该次机会或具体资源，可靠地产生准备成果，增加相关机会出现或可把握的可能。

不能把玩家长期限制为等系统发职业。准备成果与最终机会分开结算：支付拜访成本保证发生一次交流或获得信息，不保证对方一定提供理想工作。

## 6. 固定成长节奏，不固定成长轨迹

首个完整原型仍以约 12 次关键事件控制内容量和节奏，但每局的职业、人物关系、机会顺序与成果由实际路径形成。

| 体验阶段 | 约占节点 | 体验职责 | 不预设的内容 |
| --- | --- | --- | --- |
| 初步积累 | 1—3 | 接触生活、试着回应、获得第一项可用本领 | 终身职业和成功目标 |
| 尝到作用 | 4—6 | 旧积累第一次解决新问题，尝试一个阶段机会 | 一定独立创业或升职 |
| 扩大选择 | 7—9 | 在已有生活中深入，或把积累用于转向 | 所有人到同样身份层级 |
| 收获与回顾 | 10—12 | 再次兑现本领与关系，完成当前可达成的事情 | 所有人完成同一工程或获得同类结局 |

年龄与章节保持人生跨度，具体年龄表留待内容节奏验证。不会因跨过某个年龄就强制换职业或升阶。

两次回望优先安排在节点 3、6 后，形成有证据支持的处事专长。三次成长兑现约安排在节点 4、7、10，必须从当前真实积累和处境中选择，不写死为木盒、作坊订单或会馆工程。

固定的是玩家获得反馈的节奏。一个正在货栈工作的人可以因木作基础修好货箱；不会只因早年碰过木作，就被强行拉回木匠主线。

## 7. 成长爽感如何保证

### 7.1 小问题真的会变容易

已达到能力门槛、掌握相应本领的常规行动可靠成功。例如已学会普通修补后，普通修补不再随机失败。成长兑现事件保留旧门槛，不随角色能力等比例抬升。

### 7.2 逐渐拥有更有力量的行动

同样遇到急事，早期可能只能亲自赶工或拒绝；后期可以通过熟练操作、清楚协商、已有伙伴分工来解决。具体方法取决于真正获得的积累，不要求每个人都建立作坊才能扩大选择权。

### 7.3 转向仍能感到自己带着本领

搬到新地方后，老客户可能不再提供订单，但已经学会的修理仍能节省生活成本、帮助新认识的人，或成为新工作的切入点。旧关系是否还能联系，由事件记录决定。

转向可以让收入和地位暂时下降，但不应让角色退回所有事情都不会的开局状态。

### 7.4 重要投入要有可见的兑现

每次回望获得的专长，后续两个节点内应提供一次合理的使用机会；本局形成的主要能力至少在三个成长兑现节点中的一个发挥作用。

保障的是“有机会用上积累”。玩家仍可以选择不用，且这些场景不保证特定稀缺身份或理想职业出现。如果现有内容找不到合理用途，应补充场景或修正该项成长设计，不能用一个升级提示代替实际收益。

## 8. 目标随着人生长出来

开局只有背景与眼前问题。阶段目标由真实机会提出，玩家可以接受、改换或放弃：

- 在货栈站稳脚跟后，想争取负责一条运输线路。
- 经历一次亏损后，想把小店重新经营起来。
- 发现自己擅长修理后，想完成一件更难的作品。
- 因迁居远离家人后，想建立稳定生活，再把家人接来。

目标卡主要显示当前正在争取的事情和下一步条件。目标结束后，再从真实处境里产生新的目标；不保留已经不适用却一直催促玩家完成的职业任务。

愿望未能实现也会进入结局，但要同时展示其间获得的本领、实际做成的事情和得到的生活。不同结局可以有遗憾，也应有明确的积累与反馈，不能把所有变化都包装为同一种成功。

## 9. 回报、风险与继续游玩

成长收益与外部结果分别说明。练习确实提升对应能力；申请工作是否成功则受条件、竞争或对方决定影响。不能因为求职失败就取消已经完成练习的收益。

至少保留一个无需额外家底的有效行动，资源不足可通过普通工作、缩小当前目标或寻求已有关系的协作继续。替代路径必须符合人物和事实，不凭空出现救助者。

高积累带来更大的自主权、更多可行方法、更好的基础回报或更高的额外成果；保底行动保障流程继续，不承诺与充分准备者得到相同结果。

环境挫折可以影响收入、地点和阶段目标。首个原型不设计随机永久删除已学本领、一次事件清空全部资产和关系的处理，避免成长反馈在没有应对空间时被整体取消。

结局从实际事件汇总：我会了什么、做成了什么、建立了怎样的生活、和谁保持联系、哪些愿望实现或改变。没有统一的“必须开店”“必须成为大师”成功判定。

跨世档案与理解保留；本轮先验证没有任何前世加成的完整单局，跨世内容不能成为本局成长门槛。

## 10. UI 表达现在的自己

主画面显示当前处境、最相关的两项能力、家底和正在争取的阶段目标。展开角色页再看全部本领、关系与来源，避免把所有成长指标堆在顶部。

例如：

> 货栈帮工 · 初到河港
>
> 动手：熟练 / 筹划：入门 / 家底：4
>
> 眼前打算：争取独立负责下一趟货物
>
> 这只裂开的货箱，你以前修过类似的。
>
> [先修好再装货] 使用“修补木器”，减少损耗
>
> [调换装载顺序] 使用筹划，先保住易损货物

结果页分别展示外部结果、获得的成长与新机会。“你没有得到想要的职位，但修好的货箱让掌柜愿意让你试做一天”，需要由真实事件条件支持。

场景和角色形象随实际生活变化：工具、衣着、住所、工作伙伴与成果来自当前状态。不能把视觉升级写成所有人必经的学徒角落、独立作坊、大师工坊。

## 11. 现有系统如何调整

| 当前机制 | 重构方向 |
| --- | --- |
| 经历碎片和真实来源 | 保留，记录成长获得和实际使用 |
| 结果停留、确认继续、待决保存 | 保留，分别显示结果、成长与机会 |
| 人生点 | 移除，改为实际资源与机会成本 |
| 理解与两次回望 | 保留来源与版本，形成可用的处事专长 |
| 固定年龄、双主题配额 | 改为人生阶段、处境约束、成长反馈职责 |
| 事实、关系和延迟后果 | 扩展为合理机会与人生连续性的依据 |
| 身份 | 根据实际事件取得或失去，不作为预先绑定的职业路线 |
| 跨世携带 | 保留档案价值，暂不作为本局数值成长支柱 |
| UI | 突出当前处境、已会的本领与阶段目标 |

实现上需要增加能力、本领、阶段目标、机会条件及成长兑现记录。事件先过滤合理性，再权重抽样；待决结果继续冻结，防止重载改变机会或重复获得成长。

新旧规则的存档兼容另行设计，保留现有事实与档案，不把规则 7 的待决事件直接解释为新成长节点。本次只更新设计文档。

## 12. 原型与验收

第一步制作一个共享早期经历、两种后续环境，以及各自的成长兑现事件。必须能演示同样的童年选择，在不同后续机会下通向不同生活，同时旧积累在两条路径里都能合理发挥作用。

第二步扩展到完整人生，加入至少一次由真实环境引起的可选转向、主动准备、两次专长形成、三次成长兑现和按实际经历生成的成果。

规则与内容检查：

- 相同的童年经历，因后续环境与选择不同，可到达不同身份；没有隐藏的早期职业锁定。
- 同样的机会，不同积累产生不同可行方法、准备成本或结果。
- 换职业不清空已学能力，也不把专属技能无条件变成万能技能。
- 能力会影响候选机会，但不会让全部后续内容被一种早期能力垄断。
- 当前事务和人物有连续性，不把每次随机变成无关故事。
- 一项重要成长后续有合理使用机会，常规能力达标后可以可靠生效。
- 拒绝某项机会、家底不足或目标改变后仍有可推进的生活。
- 没有前世加成也有完整成长反馈；重复提交、结果恢复和来源追溯继续受测试保护。

玩家体验检查重点是：能否说出“这段生活为什么发生变化”“过去哪项积累帮到了现在”“眼下我还能主动争取什么”。需要同时感受到人生的不确定性与自己逐渐拥有的办法。
